# Jacana Prospect OS

CRM orgánico para Jacana Ocean Life.

Aplicación: https://manuelortizchimal-droid.github.io/Prospect-Os/

## Incluye
Dashboard, buscador asistido de publicaciones públicas, registro y edición de oportunidades, calificación, etapas, agenda, filtro, importación y exportación CSV.

## Seguridad y alcance
Los datos se guardan en localStorage del navegador. No existe sincronización multiusuario ni backend todavía. El repositorio público solo aloja código; no colocar bases de clientes ni credenciales en GitHub.

Buscar leads abre enlaces de consulta a fuentes externas; no extrae datos automáticamente ni ejecuta scraping. WhatsApp solo se muestra para contactos con consentimiento registrado.

## Próximo paso
Implementar Supabase/PostgreSQL con autenticación de equipo, políticas RLS, historial y auditoría. Antes de utilizar datos reales, validar despliegue, seguridad y funcionamiento en navegadores.
